功能一览

完整两级目录，快速定位

将你的提问和 AI 回答标题整理成两级目录。面对 400 多条提问，也能逐步加载目录，按关键词检索并点击跳转。

高亮、备注与书签

用四色高亮、下划线和备注标记重点，给重要内容添加书签，还能通过筛选快速回顾。

复制 Markdown 与数学公式

选中文字，一键复制为 Markdown，保留行内和独立数学公式的 LaTeX 格式，方便整理笔记和科研写作。

灵活导出与备份

Markdown、JSON 导出不限次数，可保存完整对话或仅保存书签内容，也能手动备份 Markdown 到自己的 Google Drive，以及备份和恢复 ChatGPT 标记。

用 HTML 或 PDF 保存对话

把长对话保存为一个独立 HTML 文件，即使没有网络也能阅读和回顾。

保留目录、全文搜索、高亮、备注、代码与数学公式。导出后仍能快速定位、筛选重点。

ChatGPT 支持直接导出带可搜索文字和目录书签的 PDF，方便打印与分享。

免费跳转与已加载内容

免费范围按每个 ChatGPT 聊天分别计算。前 100 条一级目录，以及聊天正文已加载过的条目均可免费跳转，二级标题跟随所属一级条目。超过此范围且仍需加载的条目需要 Pro 或有效试用。全部目录始终可查看和查找。

灵活侧边栏，减少阅读干扰

固定或浮动显示，随时折叠、隐藏或调整位置。需要目录时展开，不需要时保持阅读界面整洁。

本地优先，内容由你掌控

无需注册账户，AI 对话主要在浏览器本地处理。Google Drive 备份由你手动选择并触发。

* 不同 AI 平台的具体功能与目录加载方式可能有所不同。

免费开始，需要时再升级 Pro

免费版可查找全部目录，使用书签与标记，HTML / PDF 每周共用 3 次导出，每周一 00:00 UTC（北京时间 08:00）补满，当周剩余额度不累计。Markdown / JSON 导出不限次数。“用目录继续定位”与直接点击目录适用同一免费跳转额度。Pro 解锁全部目录跳转和不限次 HTML / PDF 导出。
