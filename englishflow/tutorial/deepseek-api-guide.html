DeepSeek API Key 申请教程

DeepSeek 用于 EnglishFlow 的 AI 写作、润色和推荐回复。你需要创建 API Key、确认账户余额，并选择一个仍可调用的模型名。

1. 开通并创建 Key

  1. 登录 DeepSeek 开放平台，进入 API Keys 页面。
  2. 点击创建新的 API Key，名称可写 EnglishFlow，方便以后识别。
  3. 创建后立即复制完整 Key；弹窗关闭后通常无法再次查看完整内容。
  4. 进入余额或充值页面，确认账户有可用余额。DeepSeek API 会从赠送余额或充值余额中扣费。

2. 填写 EnglishFlow

  1. 打开 EnglishFlow 设置页，进入 AI 与 API → AI 写作与回复。
  2. 将“调用方式”设为 DeepSeek（Pro）。
  3. Endpoint 填 https://api.deepseek.com。
  4. 模型名建议按 DeepSeek 官方文档填写。若设置页仍显示旧建议，优先使用当前官方推荐的可调用模型。
  5. 粘贴 API Key，点击 测试 API Key。成功后点 保存 API 设置。

排错清单

Insufficient balance账户余额不足，需要充值或等待赠送额度到账。
Model not found模型名不可用或已弃用，回到官方模型列表复制最新 ID。
连接超时稍后重试，并确认网络可以访问 DeepSeek API 域名。
