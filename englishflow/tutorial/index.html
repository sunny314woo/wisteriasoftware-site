AI 写作与回复

DeepSeek API Key

适用于 FluentSocial AI 的润色、语气改写、写作和上下文回复。你需要准备 Endpoint、模型名和 API Key。

打开 DeepSeek API Keys ↗ 查看官方价格 ↗
Endpointhttps://api.deepseek.com
模型按 DeepSeek 官方模型列表填写可调用 ID
计费按 tokens 计费，余额和价格以 DeepSeek 控制台为准
  1. 登录 DeepSeek 开放平台，进入 API Keys 页面。
  2. 创建新的 API Key，并立即复制完整 Key；关闭弹窗后通常无法再次查看。
  3. 确认账户余额可用，并从官方文档复制当前可调用的模型 ID。
  4. 回到 FluentSocial AI 设置页，进入 AI 与 API → AI 写作与回复。
  5. 选择 DeepSeek（Pro），填写 Endpoint、模型名和 API Key，点击 测试 API Key，成功后保存。
401 UnauthorizedKey 填错、Key 已删除，或复制时包含多余空格。
Insufficient balance账户余额不足，需要充值或等待赠送额度到账。
Model not found模型名不可用或已弃用，回到官方模型列表复制最新 ID。
连接超时稍后重试，并确认网络可以访问 DeepSeek API 域名。

价格以官网为准：DeepSeek 模型名、兼容名和 token 价格会调整，请以官方 Models & Pricing 页面为准。

OpenAI-compatible / 自定义 API

适用于 OpenAI 官方 API，或明确提供 OpenAI 兼容接口的模型服务。网页聊天地址不能直接当 API Endpoint 使用。

创建 OpenAI API Key ↗ 查看 OpenAI 官方价格 ↗
OpenAI Endpoint通常为 https://api.openai.com/v1
兼容服务Base URL 是否包含 /v1 以服务商文档为准
模型填写 API 模型 ID，不是营销展示名
  1. 在服务商控制台开通 API，并创建 API Key。
  2. 从官方开发文档复制 Base URL / API Endpoint。
  3. 复制一个支持对话或文本生成的准确模型 ID。
  4. 回到 FluentSocial AI 设置页，将“调用方式”设为 OpenAI-compatible / 自定义（Pro）。
  5. 依次填写模型、API Endpoint 和 API Key，点击 测试 API Key，成功后保存。
401 UnauthorizedKey 无效、Key 被删除，或当前项目/组织不匹配。
404 Not FoundEndpoint 路径不对，检查是否缺少或多写了 /v1。
Model not found模型 ID 不可用，或你的账户没有该模型权限。
余额/限速错误检查服务商账单、额度、限速和区域访问限制。

价格以官网为准：OpenAI 和第三方兼容服务各自计费，请以你选择的服务商最新价格页为准。

DeepL API Key

适用于页面、划词和右键直译。FluentSocial AI 会按 Key 类型选择 DeepL 端点：旧 Free key 走 Free 端点，付费或新版 API key 走正式端点。

打开 DeepL API Keys ↗ 查看官方鉴权说明 ↗
需要填写DeepL Authentication Key
Key 格式Free 旧账户常见后缀为 :fx
计费API Free / Developer / Growth 等套餐以 DeepL 账户页面为准
  1. 登录 DeepL 账户，进入 Account → API Keys & Limits。
  2. 确认账户支持 DeepL API；普通网页翻译或桌面端账号不一定包含 API。
  3. 创建或复制 Authentication Key，并按需要在 DeepL 账户里设置 Usage limit。
  4. 回到 FluentSocial AI 设置页，进入 AI 与 API → 阅读与基础翻译服务。
  5. 选择 DeepL API，粘贴 Key，点击 测试阅读翻译，成功后保存。
403 Forbidden检查 Key 是否来自 DeepL API 账户，以及是否复制完整。
456 Quota exceeded本月额度或账户限额已用完，需要等重置或升级套餐。
Key 无法新建确认当前套餐是否支持创建新的 API Key。
翻译和网页不一致API 套餐与网页版 DeepL Pro 是不同产品，能力和额度不完全相同。

价格以官网为准：DeepL 帮助中心当前说明，API Free 已无法新购；存量 Free 额度、可用地区和套餐命名请以 DeepL 账户页面为准。

Microsoft Translator API Key

先在 Azure 创建 Translator 资源，再把该资源的 Key 和 Region 填入 FluentSocial AI。

创建 Translator 资源 ↗ 查看官方教程 ↗
需要填写Azure Key、Region
免费层F0 通常包含每月免费标准翻译额度
Regioneastus、westeurope、global 等，以资源页面为准
  1. 登录 Azure Portal，搜索并创建 Translator 资源。
  2. 选择订阅、资源组、区域和定价层；个人低频使用可先看是否可选 F0 Free。
  3. 部署后进入资源的 Keys and Endpoint，复制 Key 1 或 Key 2，并记录同页 Region。
  4. 回到 FluentSocial AI 设置页，选择 Microsoft Translator。
  5. 填写 Key 和 Region，点击 测试阅读翻译，成功后保存。
401/403Key、Region 必须来自同一个 Translator 资源。
资源类型不对确认创建的是 Translator 或兼容的 Azure AI services 资源。
Region 填错不要填完整 Endpoint；只填资源页面上的区域值。
免费层不可选免费层、区域和订阅资格受 Azure 账户限制，以 Azure Portal 显示为准。

价格以官网为准：Azure Translator 的免费层、区域、币种和承诺用量价格会变化，请以 Azure 官方价格页为准。

腾讯云机器翻译 API Key

腾讯云机器翻译使用 SecretId、SecretKey 和 Region 三项信息。建议创建子用户并只授予机器翻译权限。

打开机器翻译控制台 ↗ 打开 API 密钥管理 ↗
需要填写SecretId、SecretKey、Region
免费额度文本翻译免费额度以腾讯云最新计费说明为准
费用控制可用腾讯云控制台管理后付费、资源包和账单提醒
  1. 登录腾讯云，完成实名认证，并在机器翻译控制台开通文本翻译服务。
  2. 推荐在 访问管理 → 用户 创建子用户，访问方式选择“编程访问”。
  3. 给子用户授予机器翻译相关权限，例如 QcloudTMTFullAccess。
  4. 在该用户的 API 密钥页创建密钥，复制 SecretId 和 SecretKey。
  5. 回到 FluentSocial AI 设置页，选择 腾讯云机器翻译，填写 SecretId、SecretKey 和 Region，测试成功后保存。
AuthFailure.SignatureFailure通常是 SecretKey 填错，或复制时多了空格。
UnauthorizedOperation检查子用户是否有机器翻译权限。
Region 错误确认 Region 形如 ap-guangzhou，不是城市中文名。
额度耗尽查看机器翻译控制台的资源包、后付费和账单状态。

价格以官网为准：腾讯云免费额度、后付费单价和停服规则可能调整，最终以腾讯云控制台与官方计费概述为准。
