腾讯云机器翻译 API Key 申请教程

腾讯云机器翻译使用 SecretId + SecretKey + Region 三项信息。建议创建子用户并只授予机器翻译权限，避免把主账号密钥长期放在浏览器里。

打开机器翻译控制台 ↗ 打开 API 密钥管理 ↗
EnglishFlow 需要SecretId、SecretKey、Region
当前计费口径文本翻译每月 500 万字符免费额度，超出后按腾讯云最新规则计费
费用控制后付费默认关闭；关闭时资源包耗尽会自动停服

1. 开通机器翻译

  1. 注册或登录腾讯云，按控制台要求完成实名认证。
  2. 进入 机器翻译控制台，阅读并同意服务协议后开通服务。
  3. 在控制台确认文本翻译可用。EnglishFlow 只使用文本翻译，不需要图片、语音或文件翻译能力。

2. 获取 SecretId 与 SecretKey

  1. 推荐进入 访问管理 → 用户 → 用户列表 创建一个子用户，访问方式选择“编程访问”。
  2. 给子用户授予机器翻译相关权限，例如 QcloudTMTFullAccess。如果你很熟悉 CAM，也可以收窄到实际调用所需权限。
  3. 在该用户的 API 密钥 页创建密钥，并立即复制 SecretId 和 SecretKey。
  4. 如果只是临时测试，也可以从 访问管理 → API 密钥管理 使用主账号密钥；长期使用不推荐。

3. 填写 EnglishFlow

  1. 打开 EnglishFlow 设置页，进入 AI 与 API → 阅读与基础翻译服务。
  2. 选择 腾讯云机器翻译。
  3. 填写 SecretId、SecretKey 和 Region。常见 Region 可先试 ap-guangzhou，也可以按腾讯云控制台/API Explorer 显示填写。
  4. 点击 测试阅读翻译。成功后点 保存阅读翻译设置。

排错清单

AuthFailure.SignatureFailure通常是 SecretKey 填错，或复制时多了空格。
UnauthorizedOperation检查子用户是否有机器翻译权限。
Region 错误确认 Region 形如 ap-guangzhou，不是城市中文名。
额度耗尽查看机器翻译控制台的资源包、后付费和账单状态。

价格以官网为准：腾讯云计费文档 2026-07-15 显示，文本翻译每月 500 万字符免费额度，后付费 0-100 百万字符梯度为 58 元/百万字符；腾讯云可能调整额度和价格，最终以控制台与官方计费概述为准。
