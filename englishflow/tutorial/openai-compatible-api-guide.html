OpenAI-compatible API 配置教程

该选项适用于 OpenAI 官方 API，或明确提供 OpenAI 兼容接口的模型服务。你需要准备 API Key、Base URL 和 模型 ID。

创建 OpenAI API Key ↗ 查看 OpenAI 官方价格 ↗
EnglishFlow 需要Endpoint、模型名、API Key
OpenAI Endpoint通常填 https://api.openai.com/v1
兼容服务必须支持 OpenAI 风格的对话接口，网页聊天地址不能用

1. 使用 OpenAI 官方 API

  1. 登录 OpenAI Platform，进入 API keys 页面创建新的 Secret key。
  2. 进入 Billing / Usage，确认账户有可用额度或已配置付款方式。
  3. Endpoint 填 https://api.openai.com/v1。
  4. 模型名从 OpenAI 官方模型/价格页复制。展示名和 API 模型 ID 可能不同，不要手打猜测。

2. 使用其他兼容服务

  1. 确认服务商文档明确写着兼容 OpenAI API，且支持对话/文本生成接口。
  2. 从官方文档复制 Base URL。有些服务需要包含 /v1，有些不需要，按服务商文档填写。
  3. 复制准确模型 ID，例如服务商文档表格中的 API name，而不是官网营销名称。
  4. 创建 API Key，并确认账户额度、白名单、限速或地区限制。

3. 填写 EnglishFlow

  1. 打开 EnglishFlow 设置页，进入 AI 与 API → AI 写作与回复。
  2. 将“调用方式”设为 OpenAI-compatible / 自定义（Pro）。
  3. 依次填写模型、API Endpoint 和 API Key。
  4. 点击 测试 API Key。成功后点 保存 API 设置。

排错清单

401 UnauthorizedKey 无效、Key 被删除，或当前项目/组织不匹配。
404 Not FoundEndpoint 路径不对，优先检查是否缺少或多写了 /v1。
Model not found模型 ID 不可用，或你的账户没有该模型权限。
余额/限速错误检查服务商账单、额度、限速和区域访问限制。

价格以官网为准：OpenAI 官方价格页当前按 100 万 tokens 展示模型价格，并会随模型发布变化；第三方兼容服务也各自计费。请以 OpenAI Pricing 或所选服务商的最新官方价格页为准。
