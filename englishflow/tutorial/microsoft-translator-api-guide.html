Microsoft Translator API Key 申请教程

Microsoft Translator 需要在 Azure 里创建 Translator 资源，然后把该资源的 Key 和 Region 填入 EnglishFlow。

1. 创建 Translator 资源

  1. 登录 Azure Portal，搜索并创建 Translator 资源。
  2. 选择订阅、资源组、区域和定价层。个人低频使用可以先看是否可选 F0 Free。
  3. 资源名称建议写清楚用途，例如 englishflow-translator。
  4. 完成创建后进入该 Translator 资源详情页。

2. 复制 Key 和 Region

  1. 在资源左侧菜单找到 Keys and Endpoint。
  2. 复制 KEY 1 或 KEY 2，任选一个即可。
  3. 记录同一页面显示的 Location / Region。区域资源通常必须填写 Region；如果资源显示为 global，就按页面实际值填写。
  4. 不要复制 Endpoint 到 Region 输入框；EnglishFlow 这里只需要区域名称。

3. 填写 EnglishFlow

  1. 打开 EnglishFlow 设置页，进入 AI 与 API → 阅读与基础翻译服务。
  2. 选择 Microsoft Translator。
  3. 将 Key 粘贴到 Microsoft Translator Key，Region 按 Azure 资源页面填写，例如 eastus。
  4. 点击 测试阅读翻译。成功后点 保存阅读翻译设置。

排错清单

401/403Key、Region 必须来自同一个 Translator 资源。
资源类型不对确认创建的是 Translator 或兼容的 Azure AI services 资源。
Region 填错不要填完整 Endpoint；只填资源页面上的区域值。
免费层不可选免费层、区域和订阅资格受 Azure 账户限制，以 Azure Portal 显示为准。

价格以官网为准：Microsoft Azure 当前价格页显示，Translator F0 包含每月 200 万字符免费标准翻译；S1 与承诺用量价格会随区域、币种和协议变化，请以 Azure Translator pricing 为准。
