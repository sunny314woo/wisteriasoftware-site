DeepL API Key 申请教程

DeepL 适合网页、划词和右键直译。EnglishFlow 会按 Key 类型选择 DeepL API 端点：旧 Free key 走 Free 端点，付费或新版 API key 走正式端点。

打开 DeepL API Keys ↗ 查看官方鉴权说明 ↗
EnglishFlow 需要DeepL Authentication Key
Key 格式Free 旧账户常见后缀为 :fx
当前计费口径API Free 已无法新购；存量 Free 每月 500,000 字符

1. 确认你有 DeepL API 账户

  1. 登录 DeepL 账户，进入 Account → API Keys & Limits。
  2. 如果页面能看到 API Key，说明这是 DeepL API 账户；普通网页翻译/桌面端账号不一定包含 API。
  3. 如果是新用户，DeepL 官方现在主推 Developer / Growth / Enterprise API，Free 和 Pro API 是否可用以账户页面为准。

2. 创建或复制 Key

  1. 在 API Keys & Limits 中点击 Create key。
  2. 给 Key 起一个容易识别的名字，例如 EnglishFlow Chrome。
  3. 创建后复制完整 Key。DeepL 官方建议密钥保密；不要把它放进截图、聊天记录或代码仓库。
  4. 需要控制花费时，可以在 DeepL 账户里设置 Usage limit。

3. 填写 EnglishFlow

  1. 打开 EnglishFlow 设置页，进入 AI 与 API → 阅读与基础翻译服务。
  2. 选择 DeepL API。
  3. 把 Key 粘贴到 DeepL API Key 输入框。
  4. 点击 测试阅读翻译。成功后点 保存阅读翻译设置。
