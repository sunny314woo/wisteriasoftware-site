ChatGPT Outline

A Chrome extension that turns long ChatGPT conversations into a clickable outline so you can jump to any point in seconds.

  • Clickable outline navigation for long chats
  • Jump directly to the section you need
  • Download conversations as Markdown or import them into Inbox
  • Local-first behavior for privacy and speed

ChatGPT page content is processed locally in your browser and is not uploaded to our servers.

Inbox Local for macOS

A local review app for Apple Silicon Macs that imports Markdown files, optimizes ChatGPT conversation imports, and keeps long saved material easy to preview, organize, and revisit.

  • Import Markdown files into a local-first review workflow
  • Preserve conversation navigation when previewing imported ChatGPT chats
  • AI summaries are available, and free users can use their own API key
